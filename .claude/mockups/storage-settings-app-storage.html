What changed & why (vs StorageSettings.tsx)

  • · One section heading “App Storage” replaces “Total Storage” + “Other”. Proposed new copy — needs a new storageSettings.appStorage key (the old totalStorage/otherHeading section headings are dropped).
  • · One card: the big-number/path block and the disclosure now live in a single bg-surface-container-low rounded-xl container, separated by the existing border-t border-outline-variant/40 divider (design.md §10 — the one sanctioned storage divider). No new surfaces.
  • · Size removed — the 4.9 MB that sat beside the chevron is gone; the total reads once, in large letters at the top.
  • · Description moved up, row label dropped — “Database working space…” (otherDesc) now sits under the path as the card’s explainer, and the old “Other” disclosure row becomes a slim Show details / Hide details toggle (chevron only, no icon tile). Needs new copy storageSettings.showDetails / hideDetails.
  • · Breakdown unchanged: “Working space & index” and “Leftover connection data” (with the ⋮ → “Clean up” action) keep their copy, sizes, and a11y — the real cleanup affordance.
  • · Lazy scan preserved: expanding still triggers the leftover scan (today’s toggleOther); the toggle keeps aria-expanded/aria-controls.
  • · Disclosure chevron follows the convention (design.md §7): chevron_right collapsed → expand_more expanded (right → down, never up), in text-outline — matching the NetworkStatus sections and CollapsibleCard. The old Storage code used expand_more+rotate-180 (down → up); that’s corrected.

New / dropped copy

New: appStorage = “App Storage”, showDetails = “Show details”, hideDetails = “Hide details” (× 5 locales). Dropped from this screen: the totalStorage and otherHeading section headings, and the other row label. otherDesc is reused (relocated under the total). The eager-only keys (infoText, activeSpaces, cache, reclaimable, …) stay in the file for Phase 2 but remain unrendered while eagerTransferMode is off.
